# Trabajo Final — Modelos Lineales

## Caso A: Predicción de ganancias de microemprendedores

Este repositorio contiene los archivos correspondientes al trabajo final de la asignatura Modelos Lineales.

### Objetivo
Construir y evaluar modelos estadísticos para predecir las ganancias mensuales de microemprendedores en Chile, utilizando información de la VIII Encuesta de Microemprendimiento (EME 8).

### Contenido

- `scripts/`: código utilizado para el análisis y modelamiento en R.
- `informe/`: informe final del trabajo.
- `data/`: archivos de datos, cuando su distribución está autorizada.
- `resultados/`: gráficos y resultados del análisis.

### Métodos utilizados

- Regresión lineal múltiple.
- Transformaciones de variables.
- Diagnóstico de residuos.
- Selección de variables.
- Validación cruzada.
- Ridge, LASSO y Elastic Net.
